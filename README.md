## 02  What I do

Three ways to work together. Every engagement starts with a written scope — good for both of us.

S.01

### Product build

From an empty repository to something real users can break. I handle the schema, the API and the interface, and I stay for the boring part: maintenance.

- MVPs in weeks, not quarters

- TypeScript, Next.js, Node, PostgreSQL

- Handover-friendly code, documented decisions

S.02

### Secure review

I read your code like an attacker and hand you a list of what to fix first. Offensive mindset, defensive delivery.

- OWASP Top 10 review

- Threat modeling and auth flows

- CTF player, starting bug bounty

- Written authorization and scope, always

S.03

### Rescue

For the project that was almost done eight months ago. I assess it, cut what is dead, and get it to production.

- Codebase audit in days

- Refactor without a rewrite

- Deployment, CI and monitoring

I am Simone. I have been writing software for a living for a few years, most of it full-stack TypeScript, and I like the unglamorous parts: the schema that survives the second feature, the auth flow nobody thinks about until it leaks, the error handling that means nobody gets paged at 3 a.m.
